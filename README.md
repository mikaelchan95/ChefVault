# ChefVault

Professional recipe management for the kitchen. Part of the **Winery Apps / Kitchen** suite.

ChefVault replaces scattered notebooks and spreadsheets with a fast, structured recipe database built for chefs — featuring automatic scaling, food‑cost tracking, and prep‑list generation.

> **Native rewrite.** ChefVault is now a **Kotlin Multiplatform** core with two fully native UI apps: **SwiftUI** on iOS (Apple HIG) and **Jetpack Compose + Material 3** on Android. The previous Expo / React Native app has been retired (see git history). Design spec: [`docs/superpowers/specs/2026-05-29-native-rewrite-kmp-design.md`](docs/superpowers/specs/2026-05-29-native-rewrite-kmp-design.md).

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Shared logic | **Kotlin Multiplatform** — models, scaling, costing, prep‑list aggregation, repositories, export |
| iOS UI | **SwiftUI** (MVVM, `@Observable`), consuming the shared framework via **SKIE** |
| Android UI | **Jetpack Compose + Material 3** (fixed brand color scheme) |
| Backend | **Supabase** (PostgreSQL, Auth, Storage) — reused unchanged, via `supabase-kt` |
| Networking | Ktor (Darwin engine on iOS, OkHttp on Android) |
| Session | Keychain (iOS) / default secure store (Android) |

## Getting Started

Prerequisites: **JDK 17** (Temurin), **Xcode 26.5** + iOS simulator runtime (iOS), **Android SDK** (`ANDROID_HOME`, platform 35) (Android), and `xcodegen` for the iOS project.

Supabase config is injected per platform (never committed):
- **iOS** — `native/iosApp/Secrets.xcconfig` with `SUPABASE_HOST` and `SUPABASE_ANON_KEY`.
- **Android** — `native/local.properties` with `supabase.host` and `supabase.anonKey`.

```bash
# Shared engine tests (host target, no simulator needed)
./native/gradlew -p native :shared:macosArm64Test

# iOS — link the shared framework, then build/run from Xcode
cd native/iosApp && xcodegen generate && xcodebuild -scheme ChefVault -sdk iphonesimulator build

# Android — assemble the debug APK
./native/gradlew -p native :androidApp:assembleDebug
```

## Key Features

- **Recipe Library** — search, filter by cuisine, food‑cost badges
- **Automatic Scaling** — proportional ingredient adjustment with metric/imperial conversion
- **Collections** — many‑to‑many recipe grouping
- **Prep Lists** — cross‑recipe ingredient aggregation with kitchen‑station assignment
- **Food Cost Tracking** — per‑ingredient costing with recipe‑level roll‑up
- **Auth** — email/password, Sign in with Apple (iOS), Google OAuth, password reset, account deletion
- **Image upload** — plating photos and avatars to Supabase Storage
